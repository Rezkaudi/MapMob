The four rules that touch everything

  1. 1. No wrapper. Lists return {{ '{' }}items, totalCount{{ '}' }}; one record returns the object.
  2. 2. camelCase JSON and string ids.
  3. 3. pageIndex starts at 0.
  4. 4. Real verbs — PUT, PATCH, DELETE. No _method.

Every request

Base URL
One prefix, e.g. https://api.mapmob.com.co/admin. Paths below are relative to it.
Sign-in
Authorization: Bearer <token> on every call except POST /auth/login.
Language
Text fields come back in Arabic, as one plain string.
